# ねこの家計簿

Delta Chat内で利用する、収入と支出を記録するミニアプリ（webxdc）です。日々の取引の登録、検索・修正、収支グラフの確認、JSON形式でのバックアップと復元ができます。

## 同梱ファイル

このREADMEと次のファイルを同じフォルダーに置いてください。

| ファイル | 内容 |
| --- | --- |
| [Cat_s_Household_Budget.xdc](./Cat_s_Household_Budget.xdc) | Delta Chatで開くアプリ本体 |

## 使い始める

1. Delta Chatで、アプリを使用するチャットを開きます。
2. `Cat_s_Household_Budget.xdc`をファイルとして添付し、送信します。
3. チャット内の添付アプリを選択して起動します。起動時の表示や操作は端末によって異なります。
4. 最初に入っている見本の取引20件を確認します。不要なら「設定」→「全削除」で消し、そのまま最初の自分の取引を登録します。
5. 「登録」で収支タイプ・カテゴリ・金額・日付を入力し、「登録する」を押します。メモは任意です。

詳しい手順と画面例は、同梱の操作マニュアルをご覧ください。

## 主な機能

| タブ | 操作 |
| --- | --- |
| 登録 | 収入・支出を登録。編集時は「保存する」で更新 |
| 一覧 | 月・年、収支タイプ、メモ・カテゴリで絞り込み。取引の編集と削除 |
| グラフ | 直近12ヶ月の月次集計、年次集計、推移、カテゴリ別の割合を確認 |
| 設定 | JSONエクスポート、JSONインポート、全削除 |

## 記録の保存とバックアップ

- 記録は端末内のアプリの保存領域（localStorage）に自動保存されます。この版には、チャット参加者間や別端末へ家計データを自動同期する処理はありません。
- 「設定」→「JSONエクスポート」で、`kakeibo-日付.json`というバックアップファイルを出力できます。保存先で実際にファイルが作成されたことを確認してください。
- 機種変更時は、元の端末で出力したJSONファイルを移行先へ渡し、「JSONインポート」で読み込みます。
- **インポートは追加ではなく、現在の全記録の置き換えです。** 先に現在のデータもエクスポートしてください。このアプリで出力したJSONファイルを使用してください。
- JSONには個人の収支が含まれるため、ご自身で適切に管理してください。

## 操作上の注意

- 個別のごみ箱アイコンによる削除には確認画面がありません。「全削除」には確認画面があります。削除の取り消し機能はありません。
- 全件削除して空にした状態でアプリを開き直すと、見本20件が再表示されます。見本を消した後は、そのまま自分の取引を登録してください。
- パソコンでは、一覧の取引にマウスポインターを置くと編集・削除アイコンが表示されます。タッチ端末で操作できない場合は、パソコン版で確認してください。
- 金額は1円以上の整数で入力し、登録前に日付を確認してください。日付の初期値は時刻の扱いによってずれる場合があります。
- 上部の収入・支出・残高は今月の集計です。「残高」は入力した収入から支出を引いた額で、銀行口座の実残高ではありません。「のこり」は赤字でも0円と表示されます。
- カテゴリ別グラフは全期間が対象で、一覧の年月フィルターには連動しません。「貯蓄」カテゴリも支出に集計されます。
- ファイルの保存・選択の動作は端末やDelta Chatの環境によって異なります。
